# Dayflow HRMS — Functional Specification

## 1. Employee Management
- Create/edit employee profiles (name, photo, contact, department, job position)
- Org chart view by department
- Document storage (contracts, ID proofs)
- Employee self-service portal

## 2. Attendance & Time Tracking
- Clock-in / clock-out (manual + kiosk mode)
- Shift assignment and rotation scheduling
- Overtime detection (configurable thresholds)
- Monthly attendance report export (XLSX)

## 3. Leave Management
- Leave type configuration (annual, sick, casual, unpaid)
- Employee leave request → manager approval workflow
- Leave balance auto-calculation
- Calendar view for team leave visibility
- Public holiday integration

## 4. Payroll
- Salary structure templates (Basic, HRA, DA, deductions)
- Payslip generation per employee per month
- Statutory compliance: PF, ESI, TDS
- Bulk payslip run
- PDF payslip download + email to employee

## 5. Recruitment
- Job position postings (internal + external)
- Kanban applicant pipeline (New → Screening → Interview → Offer → Hired)
- Interview scheduling linked to calendar
- Offer letter generation

## 6. Performance Appraisal
- Review cycle setup (quarterly / annual)
- KPI definition per job position
- Self-assessment + manager assessment forms
- Aggregate score dashboard

## 7. Reporting & Analytics
- Headcount trend (monthly)
- Attrition rate
- Leave utilization by department
- Payroll cost breakdown
